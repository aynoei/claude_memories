---
description: Lista todas as memorias do usuario — proprias e/ou conectadas como consumidor
---

Execute o comando /listar-memorias conforme definido na skill
memoria-compartilhada (skills/memoria-compartilhada/SKILL.md). Este comando
serve tanto para o Lado A (memorias proprias) quanto para o Lado B
(memorias conectadas) — use a tabela apropriada conforme o papel do
usuario em cada memoria.
